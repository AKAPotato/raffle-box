Node.js 运行环境（离线安装包）
================================================

node-v24.21.0-x64.msi
  Node.js v24.21.0 LTS，官方 Windows 64 位安装包
  来源：https://nodejs.org/dist/v24.21.0/node-v24.21.0-x64.msi
  SHA256：bb0eaee134f9357f22aea915ee793343e627aefc1e66488164bac6915bce2cac
  许可：Node.js 为 MIT 许可，可自由随项目分发


什么时候需要它
------------------------------------------------
只在本机「没有安装 Node.js」时才需要。
B站评论助手 bili-helper.js 是 Node 脚本，必须靠它才能跑起来。
其它 6 种抽奖模式（数字 / 座位 / 名单 / 员工表 / 分组 / 权重）
纯浏览器运行，不需要 Node，也不用装它。


怎么装
------------------------------------------------
1) 双击 start-helper.bat。检测不到 Node 时会自动打开本目录下的安装包。
   也可以直接双击本文件 node-v24.21.0-x64.msi。
2) 一路「Next」即可，安装选项保持默认（会自动把 node 加入 PATH）。
   安装需要管理员权限，公司电脑若弹出账号密码框，请让 IT 协助。
3) 装完关掉窗口，再双击一次 start-helper.bat。


怎么确认装好了
------------------------------------------------
打开命令行（Win+R → cmd）执行：

    node -v

能看到 v24.21.0 之类的版本号即成功。


不想装怎么办
------------------------------------------------
Node 装不上时，仍可用「视频页控制台脚本」兜底：
网页上展开「网络设置与手动导入」→「复制抓取脚本」，
在 B站视频页按 F12，把脚本粘到控制台回车，再把输出的 JSON
粘回「解析粘贴内容」。只是串行抓取、最多 5000 条，比助手慢。
